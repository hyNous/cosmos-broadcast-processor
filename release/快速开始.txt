小宇宙播客处理器 — 快速开始（Windows 10/11）
========================================

本文件夹是完整解压后的安装包。请勿只复制其中几个文件。

需要：Google Chrome 或 Microsoft Edge；不需要管理员权限。

一、安装 FFmpeg（处理音频必需）
--------------------------------
1. 打开 PowerShell，执行：

   winget install --id Gyan.FFmpeg --exact --accept-source-agreements --accept-package-agreements

2. 关闭并重新打开 PowerShell，确认：

   ffmpeg -version
   ffprobe -version

二、安装本地辅助程序
--------------------
1. 双击本目录中的「安装本地程序.cmd」。
2. 若出现 SmartScreen / 未知发布者提示：选择「更多信息」→「仍要运行」。
3. 看到成功提示后，按任意键关闭窗口（退出码应为 0）。

三、加载浏览器扩展
------------------
1. Chrome 打开：  chrome://extensions
   Edge   打开：  edge://extensions
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择：
   %LOCALAPPDATA%\CosmosBroadcastProcessor\extension
   （可在文件夹选择窗口的地址栏中粘贴此路径。）
4. 扩展 ID 应为：hjccjnbenicffglhjkjgoecbfdjfmafh
5. 安装完成后，可以删除下载的 ZIP 和解压目录；不要删除上面的稳定目录。

如需把运行目录放到其他磁盘（例如 E 盘），可在本目录打开 PowerShell 执行：

   powershell -ExecutionPolicy Bypass -File .\native_host\install-host.ps1 -InstallDir "E:\脚本工具\小宇宙播客\CosmosBroadcastProcessor"

安装脚本会记住该目录；以后直接运行安装入口也会继续使用 E 盘。

四、完全退出并重启浏览器
------------------------
关闭所有 Chrome / Edge 窗口后再打开。

五、第一次下载
--------------
1. 打开小宇宙单集页（地址必须包含 /episode/），例如：
   https://www.xiaoyuzhoufm.com/episode/...
2. 点击扩展图标，在侧边栏设置参数，点击下载并处理。
3. 会弹出本地任务窗口显示进度。
4. 成功后：输出目录只留下 MP3；任务状态与临时文件会自动删除。

升级
----
1. 先等待所有下载任务结束。
2. 完整解压新版本 ZIP。
3. 再双击一次「安装本地程序.cmd」。
4. 在扩展管理页点击扩展的「重新加载」。
   若从 v1.0.0 升级，或旧解压目录已经删除：先移除旧扩展，再从
   %LOCALAPPDATA%\CosmosBroadcastProcessor\extension 加载一次。
5. 完全退出并重启浏览器。

卸载
----
1. 双击「卸载本地程序.cmd」。
2. 在浏览器扩展管理页移除本扩展。
   卸载不会删除你已经下载好的 MP3。

常见问题
--------
- 连不上本地程序：确认扩展 ID、重新运行安装 CMD、完全重启浏览器。
- 找不到 FFmpeg：重新安装并确认 PATH，然后重启浏览器。
- 扩展加载失败：重新运行安装 CMD，再加载 %LOCALAPPDATA%\CosmosBroadcastProcessor\extension。
- 当前页扩展不可用：必须是 https 的 /episode/ 单集页。
- 关闭侧栏后看不到旧任务：这是预期行为（一次性任务，不保存历史）。
